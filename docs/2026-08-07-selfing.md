# Reproductive assurance — 2026-08-07

**H-assurance is NOT established. Reproductive assurance joins the four spent
routes, and it was killed by two gates the pre-registration wrote down in advance
and the first version of the verdict did not implement.**

Pre-registered in [prereg](2026-08-07-selfing-prereg.md), written before the
experiment existed. Result at n=30, d=8, 8 seeds × 5 frequencies, siteN=160.

## The registered result

| arm            | receipt exponent | realised exponent |
| -------------- | ---------------- | ----------------- |
| off (baseline) | 0.828 ± 0.506    | 0.366 ± 0.152     |
| selfing 0.5    | 0.828 ± 0.506    | 0.019 ± 0.312     |
| floorOnly 0.5  | 0.828 ± 0.506    | 0.194 ± 0.250     |
| ALWAYS         | 0.828 ± 0.506    | 0.006 ± 0.134     |

✅ **The specificity control passed exactly.** The receipt exponent is identical
across all seven arms, as it must be — selfing acts at the mother draw, strictly
downstream of the bout. Nothing leaked upstream.

❌ On the **pre-registered unpaired comparison** the intervals overlap:
0.366 ± 0.152 against 0.019 ± 0.312. Not established.

The paired delta does exclude 0 (**−0.347 ± 0.286**), and paired is the test this
design earns since every arm was handed the same founded populations. ⚠️ But that
test was chosen **after** seeing the overlap — the prereg named the quantity, not
the test — so it is post hoc and would need fresh seeds to count.

## ⛔ It is inadmissible anyway, and the prereg said so in advance

| gate          | contrast             | result             |                                     |
| ------------- | -------------------- | ------------------ | ----------------------------------- |
| admissibility | selfing vs ALWAYS    | **0.013 ± 0.251**  | ⛔ INDISTINGUISHABLE — inadmissible |
| attribution   | selfing vs floorOnly | **−0.175 ± 0.263** | ⚠️ not separable from the floor     |

The prereg's wording: _"the claim is only admissible in the regime where the
full-selfing control and the test arm are distinguishable. If the rescue appears
only where the arm is indistinguishable from full selfing, there is no result."_

That is exactly what happened. A rate-0.5 arm that behaves like total selfing
**is** total selfing, whatever its rate says. And the second gate is nearly as
bad: about half the movement (floorOnly −0.172 ± 0.145, itself excluding 0) is
**maternal-weight flattening**, not selfing — so `selfing − baseline` credits the
flattening to the mechanism, and `selfing − floorOnly` does not survive.

⚠️⚠️ **Both gates were in the pre-registration and NEITHER was implemented in the
first verdict**, which would have reported the paired delta and walked straight
past them. The prereg is the only reason this was caught; writing the traps down
before the run is what made an inadmissible positive visible instead of
publishable.

## What survives, labelled post hoc

Lineage extinction within a single generation:

| arm            | cells lost  |
| -------------- | ----------- |
| off (baseline) | 8/40 (20%)  |
| selfing 0.5    | 1/40 (3%)   |
| floorOnly 0.5  | 6/40 (15%)  |
| cost 1.0       | 14/40 (35%) |

✅ **Cost bites**: 1 → 14 lost cells when every selfed seed dies, so the assurance
is genuinely paid for and the knob is not inert.

⚠️ **POST HOC and UNTESTED.** This was not pre-registered; it was noticed because
the dropped rows differed so sharply between arms. **No significance test was
applied to these counts** — 6/40 against 1/40 for floorOnly vs selfing is
suggestive of a selfing-specific effect and is _not_ established. Do not quote
the ordering as a result.

## ⚠️ The censoring, and which way it cuts

A dropped row IS an extinction — the same event counted twice. Lost cells are
maximally-disadvantaged cells, so an arm losing more has its slope pulled DOWN
more. The baseline loses more than the treatment, which pushes the two exponents
**together**. The censoring therefore works AGAINST the hypothesis, and the gap
that survives is understated rather than manufactured. That does not rescue the
result — it fails on admissibility, not on effect size.

## ⚠️ The screen it was supposed to use could not have scored it

The published 0.70 estimator reads `perCapita`, which measures pollen received in
a single bout and never reaches the mating step. Selfing acts strictly downstream
of receipt, so **it cannot move a receipt exponent by construction**. Reusing the
existing screen would have guaranteed a null for reasons having nothing to do
with the biology. Two exponents are reported instead, receipt demoted to a
specificity control. Any future candidate acting at or after mating needs the
same treatment.

## Where this leaves the northstar

**Five routes now spent**, and the first four all attacked visitation or
attraction. This one attacked mate-finding directly, which was the right target —
and the honest reading is that it does not repair it at any rate that remains
distinguishable from abandoning outcrossing altogether.

⚠️ Not established either way: whether a **smaller** rate sits in a regime that is
both admissible and effective. The sweep this run did not do is rate → 0, looking
for a window where selfing separates from ALWAYS while still moving the exponent.
The prereg asked for that sweep and this run tested a single rate; that is the
obvious next move, and it may well find nothing, since the two gates squeeze from
opposite directions.
