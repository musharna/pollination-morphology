# Third-party material

**None — verified 2026-09-10 by the method below, not by recollection.**

This repository vendors no third-party code, fonts, images, datasets or build
dependencies. Everything in it was written for this project, with the exception of
externally published work that is **cited by DOI and not copied**.

## How that was checked

Run against the full tracked file list on `release/1.0-rc`:

| check                               | command                                                                                     | result                                                              |
| ----------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| images, fonts, binaries             | `git ls-files \| grep -iE '\.(png\|jpg\|gif\|svg\|webp\|woff2?\|ttf\|otf\|mp4\|zip\|pdf)$'` | **none**                                                            |
| package manifests / vendored deps   | `git ls-files \| grep -iE 'package.json\|package-lock\|yarn.lock\|node_modules\|vendor/'`   | **none**                                                            |
| external webfonts or CDN references | `grep -lniE 'fonts.googleapis\|cdn\.\|unpkg\|jsdelivr\|cdnjs' *.html`                       | **none**                                                            |
| external scripts in shipped pages   | `grep -hoE '<script[^>]+src="[^"]+"' *.html`                                                | 3 hits, **all local** (`sim/placement.js`, `sim/browser-bundle.js`) |

The project has no build step and no runtime dependencies: the suite runs on stock
Node, and the three browser pages load one local script each.

## Data

The 32 archives under `docs/data/*.json.gz` are **generated by this project's own
experiments** and carry no third-party content. Each is read back by the analyser named in
the result document that cites it, which is how a published figure can be re-derived
without re-running a sweep.

## Externally published work that is cited but not copied

- **The euglossine bee–orchid association database** behind
  `docs/2026-08-28-euglossine-ceiling.md` is openly deposited under CC-BY-4.0 at
  `10.5281/zenodo.7263689` (2,872 species). **No copy of it is vendored here** — verified
  by file listing. The document reports figures derived from it and cites the deposit.
  Anyone reusing those derived figures should also credit the deposit under its CC-BY
  terms.
- All other external work is cited in prose with a DOI. The full inventory of DOIs
  appearing anywhere in `docs/` or `README.md` is `docs/dois.txt` (176 entries), checked
  for retraction and resolvability — see `docs/RELEASE-1.0.md` §3.4.

## Fonts

The landing page and the three playables specify only **generic system font stacks**
(`ui-serif`, `ui-sans-serif`, `ui-monospace`, Georgia, and platform fallbacks). No font
file is bundled, and no font is fetched from a third-party host — so the site makes no
outbound request of any kind when loaded.
